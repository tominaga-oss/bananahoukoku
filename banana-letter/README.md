# バナナ君より、大切なお知らせ（手紙調ページ）

LINE の文字数制限で送れなかった長文のお知らせを、1通の「手紙」として読めるようにした静的ページです。
Vercel にそのまま置けば公開できます（ビルド不要）。

**改行と空き行の数は、いただいた文面のまま再現しています。**

---

## 1. ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本番ページ。**これ1枚で完結**（CSS込み・外部依存は Google Fonts のみ） |
| `ogp.png` | LINE / X などでリンクを貼ったときに出るサムネイル（**1080×1920＝携帯幅の 9:16 縦長**） |
| `favicon.svg` | ブラウザタブのアイコン（朱色の印） |
| `ogp.html` | `ogp.png` を作るための元データ（公開しなくてOK） |
| `README.md` | このファイル |
| `banana-letter.zip` | 上記をまとめたZIP（フォルダごと解凍して使えます） |

---

## 2. Vercel へのアップ手順（いずれか）

### A. ドラッグ＆ドロップ（一番かんたん）
1. `banana-letter.zip` を解凍する
2. [vercel.com/new](https://vercel.com/new) を開く
3. 解凍してできた `banana-letter` フォルダを、そのまま画面にドロップ
4. Framework Preset は **Other**、Build Command は空、Output Directory は空のまま **Deploy**

> フォルダごとドロップできない場合は、`index.html`・`ogp.png`・`favicon.svg` の3ファイルだけをZIPにしてドロップでも可（この3つで動きます）。
> もしくは Vercel CLI で、このフォルダで `vercel --prod`。

### B. GitHub 経由
`index.html` などの中身をリポジトリのルートに push → Vercel で Import → Framework Preset **Other** → Deploy。

## 3. デプロイ後にやること（1か所だけ）

`index.html` の `<head>` 内、`og:url` と `og:image` を **絶対URL** に書き換えてください。
LINE のプレビュー画像は絶対URLでないと表示されないことがあります。

```html
<meta property="og:url" content="https://あなたのドメイン/">
<meta property="og:image" content="https://あなたのドメイン/ogp.png">
```

同様に `<meta name="twitter:image" content="...">` も絶対URLに。

## 4. 本文のルール（書き換えるとき）

本文は `index.html` の `<main class="paper">` の中だけです。

```html
<p>皆様、お久しぶりです。</p>                       <!-- 1ブロック＝1つの <p> -->

<p class="g2">占い師のバナナ君です🍌</p>             <!-- g2＝空行2つ分 -->

<p>久しぶりに僕からメッセージが届いて、<br>驚かれた方もいらっしゃると思います。</p>
<!-- ↑ 文中の改行は <br> で、いただいた位置のまま入れています -->
```

| 書き方 | 意味 |
|---|---|
| `<p>` | 1ブロック。次のブロックとの間は**空行1つ分** |
| `<p class="g2">` | 次のブロックとの間が**空行2つ分** |
| `<p class="g3">` | 次のブロックとの間が**空行3つ分** |
| `<br>` | 文面どおりの位置での改行 |
| `<span class="mark">…</span>` | 蛍光マーカー風の強調 |
| `class="thanks"` | 朱色の太字（「本当に、ありがとうございます。」） |
| `class="last"` | 結びの一文。明朝体・大きめ・字間広め（「年末まで、残り僅か。」） |

- **署名・朱印を消したい**場合は `<div class="sign">…</div>` ごと削除してください。「承」の字を変えれば印の文字も変わります。

## 5. 調整ポイント

`<style>` 内の `:root` をいじるだけで効きます。

| 変数 | 意味 | 初期値 |
|---|---|---|
| `--ink` | 本文の色 | `#4a3f36` |
| `--accent` | 強調の朱色 | `#8f3a2c` |
| `--accent-deep` | 結び・マーカー文字の色 | `#7a2f23` |
| `--paper` | 便箋の紙の色 | `#fdfaf3` |
| `--rule` | 罫線の色 | `rgba(120,108,92,0.28)` |
| `--lh` | 罫線の間隔＝行の高さ（ここがずれると罫線と文字が合わなくなります） | `2.02rem`〜`2.5rem` |
| `--gap-2` | 「空行2つ」を罫線何本分にするか | `2` |
| `--gap-3` | 「空行3つ」を罫線何本分にするか | `3` |

**間隔が広すぎる／詰めたいとき**は `--gap-3` を `2`、`--gap-2` を `1` にしてください（整数にすると罫線とずれません）。

### 文字サイズについて（大事なところ）

スマホの文字サイズは `@media (max-width: 639px)` の `font-size: min(var(--fs), 3.5vw)` で決めています。

これは、**いただいた改行が絶対に折り返さないように**、一番長い行
「こうしてお知らせをするだけで終わってしまうのは、」（24文字）が紙幅に収まる値にしています。
Klee One は1文字あたり約 1.035em の幅があるため、24文字＝約24.9em 必要で、これが上限を決めています。

- 結果、390px の端末で本文 **約13.7px**（LINE の本文より少し小さめ）になっています。
- **文字を大きくしたい**場合はこの `3.5vw` を上げてください。`3.65vw` を超えたあたりから、長い行が折り返し始めます。
- 逆に「多少折り返してもいいから大きく」という場合は `4vw` 程度まで上げられます。

そのほか：

- 紙全体の背景（周囲の色）は `body` の `background: radial-gradient(...)`。
- 罫線は紙の下部で自然に消えるようにマスクしています（`.paper::before` の `mask-image`）。文面を増減したら `78%` のあたりを調整すると収まりが良くなります。
- スマホでは幅が足りないため、便箋の左にある朱色の縦線（`.paper::after`）は非表示にしています。
- 文字の立ち上がりアニメーションは `.paper` の `animation: rise`。`prefers-reduced-motion` の端末では自動でオフになります。

## 6. OGP画像について

- **1080 × 1920（9:16・携帯幅の縦長）** です。`ogp.html` の `html, body` の `width` / `height` を変えれば別比率でも作り直せます。
- 作り直すときは `ogp.html` をブラウザで 1080×1920 で開き、スクリーンショットを `ogp.png` として保存してください。
- 比率を変えた場合は `index.html` の `og:image:width` / `og:image:height` も合わせて書き換えてください。
- LINE のプレビューは中央付近が大きく見えます。キーメッセージ（「今年の年末をもって、活動を一旦休止します。」）は中央に置いてあります。

## 7. 動作確認済み

- **300 / 320 / 340 / 360 / 375 / 390 / 405 / 414 / 430 / 460 / 500 / 600 / 639 / 640 / 768 / 1024 / 1280 px** の全幅で、
  手で入れた改行が**1か所も折り返さない**ことを実測で確認
- 罫線と本文の行がずれないこと（`--lh` グリッド）を確認
- `prefers-reduced-motion` でアニメーション停止
- 印刷時は影・背景を落として紙面のみ出力

> もともと改行を入れていない長い一文だけは、画面幅に応じて自然に折り返します。
